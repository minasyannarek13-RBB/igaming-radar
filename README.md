# iGaming Radar

Commercial MVP for iGaming infrastructure and incident intelligence.

## Mission

Detect infrastructure degradation across operators, map shared iGaming dependencies, correlate incidents, estimate likely root cause with explicit confidence, and produce evidence of operational/commercial value faster than manual investigation.

## MVP release loop

`Scan -> Graph -> Monitor -> Correlate -> Attribute -> Alert -> ROI Proof`

## Founder Early Access release gate

- Executable runtime: BUILDING
- Blind scans: 0/30 verified
- Useful rate target: >=90%
- Fabricated dependencies target: 0
- HIGH-confidence false attribution target: 0
- Historical regression: PENDING
- Crypto E2E: PENDING
- Security: PENDING
- Soak: 0/72h
- Commercial gate: CLOSED

## Scope

MVP coverage:
- Game Provider / RGS
- Sportsbook / Platform
- CDN / Cloud
- External Change Intelligence as correlation evidence

Frozen until after the commercial gate:
- KYC/payment intelligence expansion
- Regulatory/procurement modules
- Enterprise features
- SEO-led expansion

## Proprietary product layer

Focus proprietary work on:
- iGaming topology/dependency graph
- cross-operator correlation
- attribution/root-cause confidence
- incident intelligence
- revenue-exposure logic
- ROI Proof Engine
- iGaming-specific investigation

Commodity infrastructure should use mature OSS where it materially shortens time to release without damaging product IP.

## Factuality policy

Never claim customers, pilots, partnerships, production readiness, saved GGR, or customer ROI without evidence. Value reporting must distinguish **Observed**, **Estimated**, and **Customer-confirmed** value.
